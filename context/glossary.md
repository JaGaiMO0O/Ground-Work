# Glossary

Domain terms that mean something specific here.

The point is to prevent misreads. If "account" means three different things in
three systems, an agent will silently pick one and be confidently wrong for the
rest of the session.

Record a term when it is **ambiguous, overloaded, or specific to this domain**. Do not
record general industry vocabulary - this file is loaded per task, and padding
it costs on every read.
